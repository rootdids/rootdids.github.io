BD-J Disc Structure Reference

UDF 2.50 Blu-ray ISO
 BDMV/
   BDJO/00000.bdjo    Entry point descriptor (launches org.bdj.InitXlet)
   JAR/00000.jar      Java archive containing all classes + data
   STREAM/00000.m2ts  Dummy video (required by BD spec)
   AUXDATA/*.otf      Fonts
   CLIPINF/*.clpi     Clip info
   PLAYLIST/*.mpls    Playlist
   MovieObject.bdmv   Movie object table
   index.bdmv         Disc index
 CERTIFICATE/
   app.discroot.crt   Application signing cert
   bu.discroot.crt    Binding unit cert
   id.bdmv            Disc ID
 x/offline/
   Hx1400.class       Main stage class (loaded at runtime)
   J196rR.class       Support class
   AXZXkk.class       Support class
   EkIKZR.class       Support class

JAR contents (org.bdj.*):
   InitXlet.class     Xlet entry point (implements javax.tv.xlet.Xlet)
   Boot.class         Boot sequence orchestrator
   Cfg.class          Configuration constants
   Screen.class       On-screen display
   OfflineRenderer    Offline command renderer + sub-classes
   LocalResultLedger  Result tracking

   bonk/hen.bin           Native payload (~550KB x86-64)
   bonk/local/*.bin       Metadata (guards, rules, shapes, schedule, etc.)
   bonk/local/templates/  Command templates (cmd-0002 through cmd-0046)
