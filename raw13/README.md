# Raw13 research snapshot

The six source files below were copied byte-for-byte from the supplied `raw13(1).zip` archive. The archive contained six files, not seven.

- `core.js`
- `int64.js`
- `jb.html`
- `jb.js`
- `mem.js`
- `ps4_offsets.js`

This directory is not linked or imported by the repository landing page. Its `jb.html` and JavaScript files are retained as supplied research material; they were not executed or modified. The supplied files statically reference local resources that were not present in the archive, including `hx_kevent.js`, `hx1400_port.js`, and `rpc_worker.js`, along with firmware payload and patch assets. This integration does not fill those gaps or validate runtime behavior.
